Why Core UI

Small library, scalable foundation

Every component shares the same tokens, docs surface and playground patterns.

Token-first theming

Colors come from CSS variables. Switch light and dark, or restyle the library without touching component internals.

Standalone & tree-shakable

Import only what you render. No NgModules, no runtime CSS-in-JS, and no styles leaking between components.

One registry, every page

Navigation, the index and pagination are generated from a single registry, so each new component inherits the whole docs experience.
