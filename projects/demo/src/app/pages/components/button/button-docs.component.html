Overview

pl-button renders a native <button> element, so keyboard behaviour, focus handling and form submission come from the browser. Color and variant are attributes, which means the markup stays readable and easy to diff.

API reference

💡 The host also accepts native attributes, so class, aria-label and data-* attributes pass through to the outer element.

Accessibility

  • Renders a real <button>, so Enter and Space both activate it.
  • Uses the native disabled attribute, keeping it out of the tab order.
  • Focus styles come from the consuming app — use :focus-visible outlines.
  • Keep labels descriptive. Icon-only buttons should always receive an aria-label.
