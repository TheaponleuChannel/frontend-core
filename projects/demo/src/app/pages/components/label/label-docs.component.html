Overview

pl-label wraps a native <label> and forwards the for input. Project the visible text inside the tag — no extra configuration required.

Playground

Rename the label, change the control id, and try focusing the input — the label is clickable because for matches the input id.

Accessibility

  • Always provide for. A label without it does not name the control for assistive technology.
  • Avoid relying on placeholder text — it disappears as soon as the user types.
  • Mark required fields with text (or aria-required), not only with color.
